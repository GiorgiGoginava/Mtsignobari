# Mtsignobari Homepage

A responsive React + Vite implementation inspired by the supplied Mtsignobari editorial homepage reference.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Customize
- Replace sample article data in `src/App.jsx`.
- Replace the illustrative logo mark in `BrandMark` with your original SVG asset.
- Replace remote Unsplash images with your licensed/owned imagery.
- Configure a real payment provider before accepting donations.
- Replace the sample account-holder and IBAN placeholders with verified details.
- Connect search and archive links to your actual content source.

## Important
This is a frontend implementation. The donation controls are UI-only until connected to a secure payment provider/backend. Article modal content is sample text and should be replaced with published content. The example contact destination is intentionally nonfunctional.
